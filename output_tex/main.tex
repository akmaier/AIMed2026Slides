\begin{frame}[t]{The Proceedings}{Prepared with the help of agentic AI}
\vspace{0.4em}
\begin{itemize}\itemsep=0.3em\large
  \item Three months from idea to event \,--\,
        also for the Book of Abstracts.
  \item An AI coding agent reformatted every submission

  \item Automated checks: word and reference limits,
        required sections, ethics-statement heuristic,
        track-specific rules.
  \item Flagged items returned to authors for resolution.
  \item Editors remain responsible for the final content.
